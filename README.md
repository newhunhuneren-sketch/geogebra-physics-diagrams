# GeoGebra 物理教学作图技能

把自然语言和公式变成可编辑、可审核的 GeoGebra 二维图、三维图与动画。

重点不是生成一张看似正确的图片，而是：**数学建模 → 实际 GeoGebra 构造 → 数学与视觉检查 → 用户评审 → 修订**。

## 在 ChatGPT 项目中使用

1. 创建一个名为“GeoGebra 作图”的项目。
2. 在项目的“源”中上传 `GeoGebra作图技能-分享版.md`。
3. 在项目说明中加入下面的要求，并从这个项目内开始作图对话。

```text
你是我的 GeoGebra 作图助手。每次作图前先读取并遵循项目文件《GeoGebra作图技能-分享版.md》。先检查实际工具能力：有浏览器控制工具时，在真实 GeoGebra 中执行、检查并给我预览；没有时提供可运行的脚本或网页文件，并明确说明尚未运行。不要用 AI 图片代替数学构造，不要声称未执行的脚本已经验证。根据我的评审逐步修改。
```

**上传文件不等于正式安装插件。技能规则本身不会授予浏览器、账号或本地硬盘访问权限。** 自动操作 GeoGebra 需要接收者环境提供并授权相应工具；否则仍可按规范生成脚本，由用户运行。

## 第一张图示例

```text
请画两端固定的驻波：
D(x,t)=2A sin(kx) cos(wt)，A=1，k=pi，w=1，L=6。
横轴 x，纵轴位移 D，波形用黑色粗实线。
只显示 t 滑块，可以手动拖动，也能自动播放。
给我可见预览，检查两端位移始终为零。
```

也可以请求：“画两个点波源的干涉包络面”“画球面波与观察屏的交圆”“把这张图中被底面遮挡的曲线改成浅色虚线”。给出自己的公式时，以你的符号和边界条件为准。

## 包含的经验

- 行波、驻波、反射、同向叠加、固定端和自由端边界。
- 圆形波、球面波、等相位线、包络面与相长／相消轨迹的区别。
- 三维截面方向、轴的约定、明暗、遮挡、剖视缺口与清晰的相机视角。
- 真正的圆和交点、精确公式与近似关系、数学残差检查。
- 干净的 PPT 截图、同一参数的配套图、动画与可编辑文件交付。
- 根据评审改进技能，同时明确实际工具能力和验证状态。

## 标准技能目录

```text
plugin.json
skills/
  geogebra-physics-diagrams/
    SKILL.md
    agents/openai.yaml
    references/
      math-and-style.md
      3d-depth.md
      scripting-and-validation.md
```

支持本地技能的宿主应使用完整技能文件夹，不能漏掉 references。支持插件的宿主可按其当前安装流程使用根目录的 `plugin.json`。本仓库不提供 MCP 服务、浏览器扩展或自动安装程序，也不是已发布到公开插件目录的插件。
