# GeoGebra 物理教学作图技能

分享版 v1.0，2026-10-10。目标：自然语言需求 → 数学模型 → GeoGebra 构造 → 实际运行和视觉检查 → 用户评审 → 修订。

## 先检查能做什么

- 检查本次对话实际提供的文件、浏览器和执行工具。技能是一组工作规则，不会凭空提供浏览器控制、文件权限、GeoGebra 连接或账号权限。
- 有浏览器控制工具时，实际打开 GeoGebra 并操作；有文件与执行工具时，可生成嵌入 GeoGebra 的本地网页。
- 没有浏览器控制工具时，提供可运行的命令文件或 HTML 文件，并明确说尚未在 GeoGebra 验证，不能把生成源文件说成已画好或已截图。
- 网络不可用时保留脚本，说明在线 applet 未能加载。不要绕过安全警告、登录限制或权限限制。
- 一般作图不必登录 GeoGebra；如需登录、账户保存或授权，由用户按当前环境的权限流程处理，不索取密码。

## 工作目录和交付物

首次使用选择用户授权的 `geogebra` 工作目录，不依赖特定电脑的盘符。已有目录则复用。

```text
geogebra/
  scripts/    每张图的命令文件、参数和必要的网页
  exports/    可编辑 .ggb、PNG、GIF 或 MP4
  reviews/    评审意见和修订记录
```

- 文件用日期加主题命名，例如 `2026-10-10-fixed-standing-wave.ggbscript`。
- 参数、公式、视角和样式应可复现。截图与对应脚本保持同一版本。
- 不覆盖用户已认可的成品来试验新版本。没有本地硬盘权限时提供可下载文件，不声称已存到用户硬盘。
- 本机 localhost 链接不能在另一台电脑直接使用，分享时应附上实际文件及所需资源。

## 执行流程

1. 判断教学目标、维数、静态或动态、变量与单位。只有缺失信息会改变物理含义时才追问，其余采用合理默认并简短说明。
2. 优先保留用户给出的方程、符号和正负号。检查边界、相位、定义域、单位以及精确关系和近似条件。
3. 写命令时阅读附录《数学与配图约定》和《脚本与检查》。做三维图时再阅读《可见三维感》。目录版文件分别是 `references/math-and-style.md`、`references/scripting-and-validation.md`、`references/3d-depth.md`。
4. 二维用 GeoGebra Graphing 或 Classic；三维用实际 GeoGebra 3D 视图，不用伪三维图片冒充。
5. 执行命令并检查构造失败、对象定义、滑块联动和实际渲染。不要仅检查脚本文本。
6. 调整范围、相机、遮挡、曲线密度和文字。需要截图时导出干净视图，并按 PPT 中的实际显示大小复查。
7. 在聊天中先展示可见预览供审核，随后提供已生成的脚本、可编辑文件或导出图。明确哪些做了验证、哪些尚未验证。
8. 根据反馈修改。用户授权持续学习时，记录可推广的偏好；其个人偏好不自动变成其他用户的固定规则。没有持久化权限则给出更新后的技能文件，不假装跨对话已记住。

## 对话习惯

- 中文需求默认中文标签。先做实际图，不把任务停在建议或长篇说明上。
- “基于这张图”表示复用现有坐标、公式、参数和视角，只修改所要求的内容。
- “噪音”“我在 PPT 自己加”表示输出少标签或无标签底图，保留用户指定的点和方向。
- “二维波”通常指在二维介质上传播，不等于只能画二维图；先分清俯视波前、三维位移曲面和包络面。
- “横截面”不能只凭画面方向判断，要写出固定的坐标、平面方程和曲线参数。
- “让它动起来”默认由时间变量驱动真实函数。相机旋转不替代物理波动动画。
- 学习新偏好时记录原因，例如“相邻截面挡住了关键波谷”，不要只记录某张图的旋转角度。

## 最终检查

数学真实、颜色含义一致、图面不拥挤、标签不压曲线、隐藏线符合真实遮挡、截图清晰、交付文件存在。3D 还要实际测试拖动旋转；动画还要检查周期和粒子运动。未经用户审核的版本标为待评审，不宣称用户已认可。
