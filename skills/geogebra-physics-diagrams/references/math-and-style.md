# 附录：数学与配图约定

## 统一原则

- 数学计算优先于美观。圆、交点、曲面、线段必须真实对应方程，不能凭视觉摆放。
- 使用统一单位，并区分物理真实比例与示意比例。改变空间或时间轴显示比例时说明，不偷偷改变物理参数。
- 真正的二维标准圆必须保持 x、y 等比例；检查导出的图，不只检查坐标设置。
- 参数使用 ASCII 对象名，显示标签可以用中文、希腊字母和真正的上下标。保留用户的 `w` 或 `omega` 命名，不强制替换。
- 用户指定的配色优先于以下默认值。不要让同一颜色同时表达不同时间、不同波源和不同物理量而不说明。

## 一维行波、驻波和叠加

向右传播的常用形式：

```text
D(x,t) = A sin(phi00 - k x + omega t)
lambda = 2 pi / k
T = 2 pi / omega
v = omega / k
```

波源位于原点、固定反射端位于 L，若原波采用上述符号，可用：

```text
R(x,t) = -A sin(omega t - 2 k L + k x)
S(x,t) = D(x,t) + R(x,t)
```

- 校验 `S(L,t)=0`。只有两端固定的本征驻波才另外要求 `kL=N pi`；不要把任意源驱动反射情形误说成两端固定本征模。
- 默认第一列波蓝色虚线，第二列波或反射波红色虚线，合成波黑色较粗实线。方向箭头与对应波同色。
- 展示范围按教学需要选几个周期，边界模型限制在其实际区间。源间单波区域和叠加区域有区别时画出区别。
- 两端固定模可写 `B sin(N pi x/L) cos(omega t)`；两端自由模可写 `B cos(N pi x/L) cos(omega t)`，`N>=1`。固定端是节点；自由端的空间导数为零，端点是腹点。
- 驻波的波节位置不随时间移动。多个 snapshot 用同一方程、同一时刻集和统一颜色；不要把它们误画成平移的行波。
- 原波精确重合时说明重合，或以交替颜色虚线表示，不能让一个颜色完全吞掉另一个。
- `A,k,omega,L,phi00` 可以是可调参数；简洁审核页通常只露出 t 滑块，其余参数仍可编辑。
- 选取质点时固定其横坐标，位移和 P 标签一起上下动。质点不随波峰沿 x 平移。
- 需要对比局部振幅时，P 可取腹点，Q 取节点，R 取其间的点；位置由振幅函数计算，不凭肉眼判断。

## 二维配图与 snapshot

- 横轴 x、纵轴位移 D。振动图则横轴 t、纵轴 D，避免把两种图混为一谈。
- 截图隐藏滑块、代数面板和工具栏，负 x 区域只留必要边距，不裁断波峰和方向箭头。
- 时刻标签用 `0,T/6,T/4,T/2` 等 T 表达，放在空白区而不是压住曲线。
- 对比两个时刻可用 t 蓝色、t' 红色；波前线型另用于波峰实线、波谷虚线，避免同一线型承担两种含义。
- 拥挤时分成相同尺度的两幅图，而不是继续叠标签。传播距离应追踪同一个波峰，标 `v(t'-t)`，不是任意两个峰的距离。
- 土黄色连续性填充表示相邻波峰、波谷之间仍有连续介质与位移，不能把未画的区间误画成空白缺口。
- 配套 2D、3D 图必须使用同一参数和同一 x0 或 t0，数值验证它们的对应截面一致。

## 圆形波、等相位线和包络

```text
r = sqrt((x-xs)^2 + (y-ys)^2)
D(r,t) = A sin(omega t - k r + phi0)
```

- 俯视等相位线是圆，三维空间点源的等相位面是球面。圆形水波的三维位移曲面不是球面。
- 360 度径向曲线图使用多条真正的径向正弦曲线，可加一张竖直径向截面突出其中一条。
- 常振幅圆形波是理想化模型；不默认它具有真实水波或光波的距离衰减规律。
- 等相位线、等位移线、包络极值线不是同一种对象。用户说相位时，可采用含 t 的振荡项，须明确所采用的分解约定。
- 两个等频等振幅源令 `theta_i=omega t-k r_i+phi_i`，则

```text
D = 2A cos((theta1-theta2)/2) sin((theta1+theta2)/2)
B(x,y) = 2A abs(cos((theta1-theta2)/2))
```

- `B` 是振幅包络，不是某时刻位移，也不随 t 变化。
- 固定平均相位时，`r1+r2` 为常数，非退化轨迹是椭圆；三维对应椭球。存在条件是路径和大于两源间距。
- 带符号的振幅因子为负时，可折入 pi 的相位跳变；振幅为零处局部相位无定义。不能不说明约定就把平均相位与非负振幅的局部相位混同。
- 固定相位差时，`r1-r2` 为常数，非退化轨迹是双曲线；三维是两叶双曲面。它们不是合成波的等位移线。

## 相长、相消轨迹和退化情况

等振幅、同频、同初相源：完全相长满足 `r1-r2=N lambda`，完全相消满足 `r1-r2=(N+1/2)lambda`。其他初相位须加入源初相差。振幅不等时不能宣称完全相消为零。

两源距离为 d，设路程差为 delta：

- `0<abs(delta)<d`：双曲线／两叶双曲面。
- `delta=0`：垂直平分线／平面。
- `abs(delta)=d`：沿两源连线的退化射线，不是普通双曲面。
- `abs(delta)>d`：没有轨迹。

默认相长红色实线，相消蓝色虚线；用户要求全黑则用实虚线区分。每条线的 N 和路程差必须由方程确定。三维包络上的脊线要放在真实高度 B 上，不能只贴到底面冒充曲面极值。

沿源连线、两源之间，理想等振幅相向传播可形成驻波；两源外侧是同向传播。只有指定参数满足相长条件时，外侧射线才是最大振幅轨迹。高阶退化最大线附近可能是很宽的平顶，不必强行造出尖脊。

## 球面与观察屏

若 `S=(0,0,0)`，观察屏 `x=L`，球面半径 R，则截面圆心 `O=(L,0,0)`、半径 `sqrt(R^2-L^2)`。

- `R>L` 才有非退化交圆，`R=L` 是相切点，`R<L` 无交线。
- 用真实球面、平面和交线构造，屏幕在透视图中倾斜不意味着物理屏幕变形。
- 用户需要截面感时，球壳应延伸到观察屏后，而不是把球壳截止在屏面。切面与剖视缺口是两件不同的事。
- 左侧光源、传播方向、右侧屏幕形成清楚层次。交圆应清晰附着于屏面，不凭视觉绘椭圆。

## 双缝与精确交点

- 空间模型默认光沿 +x，缝沿 z 延伸、沿 y 分开，挡板和屏幕分别为平行 y-z 平面；指定斜入射时另建实际几何。
- 线波源代理点、单缝等效点源、远场平行光等均是带条件的近似，不能把有限距离所有点的路程差声称为精确相等。
- 缝宽 a、缝长 b、中心距 d、屏距 L 的数值与单位标在对应尺寸线上。有效观察区域与整块屏幕分开表达。
- 同相位圆示例应按 `rho_n^2=2nLlambda+n^2lambda^2` 画标准圆。
- 圆心 `(-d/2,0),(d/2,0)` 的交点有 `x=(rho_n^2-rho_m^2)/(2d)`，再由圆方程算正负 y，并检查根号非负。
- 精确 x 随 n、m 可有微小差异；近似 `x_k≈kLlambda/d` 另画浅虚线，不能把精确点强制投到它上面。
- 圆太多使教学图过小时，减少编号范围并放大几何区域，保留满足教学关系的真实交点。
