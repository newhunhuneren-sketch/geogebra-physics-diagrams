# 附录：脚本、导出和验证

## 实际执行路线

1. 有合适的浏览器控制工具：在 GeoGebra 网页运行。
2. 有文件和执行工具：生成嵌入实际 GeoGebra applet 的 HTML 辅助页，使用已有预览服务或用户授权的本地服务打开。
3. 工具不可用：交付命令文件及最短操作说明，标明尚未实际运行。

常用入口：

- 二维：`https://www.geogebra.org/graphing` 或 `https://www.geogebra.org/classic`。
- 三维：`https://www.geogebra.org/3d`。
- 网页嵌入脚本：`https://www.geogebra.org/apps/deployggb.js`；三维采用 `appName: "3d"`，或显式开启 Classic 的 3D 视图。

这些入口依赖网络及浏览器能力。不得把“能搜索网页”当成“能操作网页”。遇到 API 或命令不确定，查当前官方 GeoGebra 文档或实际测试。

## 构造规则

- 先参数，后对象，再样式，最后视图。每行一个构造命令，便于定位错误。
- 点用大写名称，如 O、P、S；避免 `xAxis` 等内置对象名冲突。公式中的自变量与独立参数分开。
- 三维曲线使用参数曲线 `Curve`，曲面使用 `Surface` 或原生隐式曲面。标准几何优先 `Circle`、`Sphere`、`Intersect` 等对象。
- 通过 `evalCommand` 执行时记录失败命令，并检查对象是否存在、是否 defined；不能把所有失败都当作样式命令可忽略。
- 样式可用 `SetColor`、`SetLineStyle`、`SetLineThickness`、`SetFilling`、`ShowLabel`、`SetCaption`，或 applet 的对应公开 API。
- 构造 API 和读写 XML 的可用性取决于版本，先测试。不要把某个版本的隐藏内部对象当稳定接口。
- 自动生成的辅助点、边、面和参数要逐一处理标签及可见性，避免打开图时满屏对象名。
- 真正下标采用 GeoGebra 数学标签或 LaTeX 文本；截图中检查撇号、下标、中文是否清楚。
- 程序化浏览器操作须遵守当前工具边界。若页面求值只允许读取，则通过网页自身控件触发构造，不绕过限制调用任意写操作。

## 动画

- 时间变量范围与 `T=2pi/omega` 一致，设置适当增量、速度和循环方式。依赖 t 的波形和点实时更新。
- 区分静态空间包络与随时间变化的位移；包络一般不随 t 起伏。
- 选定质点横坐标固定，验证节点恒为零、自由端导数为零、固定端位移为零等边界。
- 请求 GIF 时给 GIF；面向 PPT 可优先建议 MP4，但遵从用户指定格式。
- MP4 通常用 H.264、yuv420p，实际查找本机 FFmpeg，不硬编码别人的安装路径。
- 视频长度、帧率、分辨率按需求设置。需要 15 秒或 30 秒时生成实际该时长并检查，不仅修改文件名。
- 在聊天中先展示预览再同步成品，除非用户已直接要求保存。截图隐藏控制，但交互版本保留播放暂停和 t 滑块。

## 数学验证

- 交点代回全部所属方程，计算残差并设置与数值尺度相称的容差。
- 检查曲线或曲面定义域、开方非负、分母非零、退化参数以及边界值。
- 物理关系核对波向、源初相、空间相位差、周期、振幅和单位。
- 按用户模型分别验证精确公式与近似公式；不因图上分辨不出差异而把近似当等式。
- 比较图共享同一组参数、时刻、颜色和尺度，避免配套图讲不同情景。

## 视觉验证与导出

- 实际打开最终图，检查构造错误、空白画布、对象数量、滑块、视角、字体、裁切和遮挡。
- 静态 PNG 去掉工具栏、代数列表、滑块和多余留白。高清按需要导出，例如长边 2400 像素以上，并检查实际像素尺寸。
- 原生 PNG 导出 API 对 3D 缩放的支持可能与二维不同；不能只凭请求倍率宣称高清。
- 优先提供真实 `.ggb` 文件，保留可编辑构造和相机。改后重新导出，而不是给旧截图。
- `.ggbscript` 是文本命令文件，不等于 `.ggb`；改扩展名不会转换格式。API 支持时可使用 `getBase64` 保存原生 GGB。
- 输出清楚列出“已生成”“已运行”“已导出”“待审核”，不要把这些状态混为一谈。
- 用户调整过的视角或位置先保存再修改，避免刷新页面丢失其工作。

## 评审与持续改进

记录日期、教学问题、用户反馈、改法和验证结果。仅在获得持久化授权、具备写入能力时更新本地技能；其他环境返回一个修订版文件。新使用者可以保留这套默认风格，也可以覆盖个人偏好。
